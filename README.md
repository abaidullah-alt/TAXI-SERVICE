# 🚕 Taxi Booking System

A complete taxi booking platform with real-time ride tracking, driver portal, and admin dashboard. Built for a real taxi business.

🔗 **Live Demo:** https://abaidullah-alt.github.io/TAXI-SERVICE/

## Features
- 📱 Responsive booking wizard (pickup, destination, date/time, passengers)
- 📍 Real-time ride tracking via shareable public link
- 💬 Passenger-driver chat
- 🚕 Driver portal - accept rides, update status
- 🔐 Admin dashboard - manage bookings, assign drivers
- ✉️ Email confirmations with tracking links

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP (file-based storage - no database required)

## Run Locally
Requires PHP 8.2+:

    git clone https://github.com/abaidullah-alt/TAXI-SERVICE.git
    cd TAXI-SERVICE
    php -S localhost:8000

Then open http://localhost:8000
